# 站点可靠性与可访问性优化设计

## 目标

在不改变作品集视觉方向和媒体结构的前提下，修复联系方式交互、统一公开信息、提升弹窗键盘可用性，并把静态质量检查接入发布流程。

## 设计

- Contact 的微信条目改为按钮语义，使用 Clipboard API 复制微信 ID；成功和失败都显示短暂、可读的状态，并提供不支持 Clipboard API 时的文本回退。
- DIT 工作流和项目详情弹窗记录触发按钮，打开后聚焦关闭按钮；Tab/Shift+Tab 在弹窗内循环，Escape 关闭并恢复触发按钮焦点。
- 统一 Cloudflare Pages 项目名为 `fifteenshowreel`，更新页脚日期和 HTML/OG 描述。
- 引入固定版本 ESLint 及 React 相关插件，增加 `npm run lint`，并在 GitHub Actions 的构建前执行。
- 保持现有视频分段和 HLS 动态加载策略，新增可执行的资源阈值检查，不在本次变更中重新编码媒体。

## 验收标准

- 微信按钮复制成功时显示成功反馈，失败时显示可理解的回退提示，不发生页面跳转。
- 两个弹窗可仅用键盘打开、浏览、关闭，关闭后焦点回到原触发按钮。
- 本地 lint、现有测试和生产构建全部通过。
- GitHub Actions 成功完成并部署最新 commit，线上首页返回 200。
