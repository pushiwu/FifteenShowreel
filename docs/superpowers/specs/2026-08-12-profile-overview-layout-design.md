# 个人概览版式改版设计

## 目标

将个人站点的个人概览区域改为参考图所示的无边框编辑式版面：人物视觉位于右侧，创作内容位于左侧，底部以三条纵向信息栏承载核心作品、工作维度、奖项与入围三个入口。联系方式不再出现在个人概览区域，只保留在页面末尾的 Contact。

## 已确认方向

- 使用 `02_参考与人物素材/个人照片/微信图片_20260807234623_367_174.png` 替换当前 About 图片。
- 人物放在右侧，作为主要视觉。
- 左侧保留“状态先于陈述”和现有创作陈述正文。
- 取消照片卡片、白色相框和内容面板的独立边界。
- 透明人物图、蓝色轮廓、站点背景和文字融为一个连续画面。
- About 中移除联系方式。
- 联系方式放在最后的 Contact 区域。
- 重新排版“核心作品、工作维度、奖项与入围”，三个入口继续跳转到对应的详细区块。
- 不删除现有 Projects、Expertise、Resume 的详细内容和既有交互。

## 页面结构

个人概览区域使用 12 栏网格：

- 左侧 5 栏：英文栏目标签、中文标题、三段创作陈述。
- 右侧 7 栏：透明人物 PNG，使用绝对定位与轻微渐变/阴影融入背景。
- 底部横跨内容区：三条竖向入口栏，分别显示数量、中文标题、英文标题和跳转箭头。

入口链接：

- 核心作品 -> `#projects`
- 工作维度 -> `#expertise`
- 奖项与入围 -> `#resume`

Contact 继续作为页面最后一个主区块，并保留现有电话、邮箱、微信链接。

## 响应式策略

- 桌面端：左文右图，底部三栏入口。
- 中等宽度：人物仍在右侧但缩小视觉占比，入口栏保持三列。
- 移动端：左侧内容先出现，人物视觉随后出现，入口栏变为单列；不再使用卡片框。
- 图片使用透明 PNG 的原始 alpha，不生成新的背景填充。

## 验收标准

- About 使用新 PNG，旧 `about-profile.jpg` 不再被引用。
- 页面视觉上人物位于右侧，文字位于左侧。
- About 中不再出现电话、微信、邮箱或联系方式网格。
- About 中存在三个入口，分别可跳转到 `#projects`、`#expertise`、`#resume`。
- Contact 仍是页面最后一个主区块，并保留三个联系方式。
- 桌面与移动视口均无横向溢出。
- `npm.cmd run build` 通过。
- 浏览器检查关键 DOM、入口链接和控制台错误。
